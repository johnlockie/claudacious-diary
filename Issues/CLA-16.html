Please stack the theme selector vertically instead of horizontally. It should float and not scroll with the rest of the site. Also, move the "Read this to me" button to the top right of each post, and instead of a "PLAY" button, use a lips icon (human lips, emoji or something like that).

What was done

AskBeforeAfter
Stack the theme selector vertically The five theme buttons sat side by side in one row (wrapping onto more rows on narrow screens). The buttons are stacked in one column, one theme per row, all the same width, with their labels left-aligned.
It should float and not scroll The selector was already pinned (position: fixed) to the top-right corner of the window. No change needed. It stays pinned to the top-right corner and floats over the page while the posts scroll underneath it.
Move "Read this to me" to the top right of each post The play button and voice picker sat in a row at the top left of each post, above the date. The button and voice picker now sit in the top-right corner of each post. The date and title flow beside them on the left. The voice picker is still next to the button, so the reader can still choose a voice.
Lips icon instead of "PLAY" The button read ▶ Read this to me, and ■ Stop reading while reading. The button is now a lips emoji, 👄. While a post is being read it changes to ■ (stop) and stays highlighted, the same way it did before. Click it again to stop.

What was changed

  • index.html:
    • .theme-switch: changed from a wrapping row to a single column (flex-direction: column). It was already position: fixed. Its buttons are left-aligned so the labels line up.
    • .read-aloud: the control bar now floats to the right at the top of each entry. It is capped at 55% of the entry's width so the date and title still have room on a phone, and the voice picker shrinks to fit.
    • The read-aloud button shows 👄 (U+1F444, "mouth") and uses the system emoji font so it shows in colour. It has an aria-label and a tooltip of "Read this to me", or "Stop reading" while reading, so screen readers and mouse hover still say what it does now that the button has no words.
    • Doogie Howser theme: set the lips button size so it isn't oversized at that theme's larger text size.
  • Added this record, Issues/CLA-16.html.
  • The reading itself (voices, how a post is split up and spoken, highlighting) did not change. No themes or entry text changed either.
